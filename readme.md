# Kuce w necie

Gra zręcznościowa/sieciowa napisana w C++ (Qt / SFML).

## Pobieranie i instalacja

1. Wejdź w sekcję [Installer](https://github.com/ErykGoraj/Kuce-w-necie/installer).

2. Pobierz plik `Kucyki_Setup.exe`.

3. Zainstaluj i uruchom grę ze skrótu na pulpicie.

## Uruchomienie ze źródeł

* Wymagany kompilator MSVC (64-bit) oraz Qt Creator / CMake.

* Otwórz `CMakeLists.txt` i zbuduj projekt w trybie **Release**.
